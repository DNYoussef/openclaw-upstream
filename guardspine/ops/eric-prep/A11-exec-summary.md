# GuardSpine: One-Page Executive Summary

**For CISOs, CTOs, and CFOs at Regulated Companies**

---

## What Is It

GuardSpine is an open-source governance layer that creates tamper-proof audit trails for every code change -- whether written by humans or AI. It is not a code review tool. It is insurance against the question: "Who is liable when AI-generated code causes a breach?"

---

## Who Buys It

**Primary buyer:** CISO or Chief Compliance Officer at companies with 500+ engineers in regulated industries (finance, healthcare, insurance, legal).

**End users:** Developers install it as a GitHub Action in 5 minutes. They keep working the way they already work. The CISO gets the dashboard and evidence.

## Why Now

1. **AI is writing code faster than anyone can review it.** 65% of PRs ship with minimal or zero review (Graphite, 2025). AI-generated code has 1.7x more defects (CodeRabbit) and 2.74x more security issues (Veracode).

2. **Regulations are closing in.** EU AI Act enforcement begins August 2026 (fines up to 7% of global turnover). DORA has been enforceable since January 2025 (2% of turnover). SOC 2 auditors are asking for code-level governance evidence.

3. **Nobody else does this.** Vanta and Drata prove your infrastructure is configured correctly. Snyk and Checkmarx find vulnerabilities. Neither proves that AI-generated code was properly governed before reaching production. That is the gap GuardSpine fills.

4. **3-year technology moat.** Exclusive partnership with Proprioceptive AI (55 provisional patents) for cognitive probe integration. Deterministic confidence scores from model hidden states -- proving not just what an AI said, but whether it was confident or guessing.
