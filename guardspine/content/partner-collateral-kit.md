## 1. One-Page Brief: What GuardSpine Does

**One sentence:** GuardSpine makes every risky code change provably governed without slowing the team.

**The gap:** GitHub tells you what changed. GuardSpine tells you what it means that it changed.

**How it works:**

- Free GitHub Action (codeguard-action) runs AI code review on every PR
- Risk-classifies changes into 5 tiers (L0 trivial through L4 critical)
- Produces signed evidence bundles -- cryptographic proof that review happened
- Proportional: typo fixes get waved through, auth changes get council review

**Who it's for:**

- Engineering teams using AI to generate code (Copilot, Cursor, Claude)
- Companies facing SOC 2, HIPAA, ISO 27001 audits
- CISOs who need proof of governance, not just approval checkboxes

**What makes it different:**

- Proportional review (not everything gets the same treatment)
- Evidence bundles (cryptographic proof, not just status checks)
- AI reviewers are the review panel (multi-model consensus, not human bottleneck)
- Open-source kernel + free GitHub Action (no vendor lock-in to start)
